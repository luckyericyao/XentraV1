# Xentra 本地续轮验收

范围：当前仓库与全部未提交进度。保留现有集团架构、双语文案、导航与品牌样式；不把本地构建描述为线上发布。

## 上一轮收尾

1. **双语错误页。** 旧路由返回 404，但正文只存在于脚本载荷，与 [Next.js 的同类问题](https://github.com/vercel/next.js/issues/100596) 一致。现在首个 HTML 就包含正确的语言、说明、跳过链接与返回入口，保留 404 和 `noindex`，不反射请求数据。11 月 7 日本机 Safari 实测两种语言的恢复页和返回入口，中文页的 EN 链接进入英文首页。未测试实体手机或关闭浏览器全局 JavaScript 设置；响应本身不含脚本。
2. **发布配置与证据。** 自定义业务入口不再改写三张截图的来源或九条历史证据链接。合成配置验收了自定义公开记录、路径与端口、未核验邮箱隐藏、显式标记的邮箱链接及 JSON-LD。公开邮箱只接受单个普通地址，不接受多收件人、显示名或 URL 参数。
3. **资源与清理。** 检查四个分享图的 PNG 尺寸，以及双语页面实际引用的三个优化图片请求。清理逻辑只在确认 Darwin 进程组已空时处理退出过程中的 `EPERM`；仍有成员就保留失败。

11 月 9 日补跑最终版本：**83 个单元测试、lint、Next.js 构建及类型检查通过**。默认配置 763 项、自定义公开记录 767 项、合成邮箱模式 751 项 smoke 断言通过。三个临时监听均已释放。真实域名、邮箱投递、外站内容和公司资料没有重新核验。

## 下一目标：隔离构建与正在运行的预览

优先原因：当前三种配置共用仓库 `.next`，虽然完整运行会重建默认配置，但失败、中断或并发验收会影响本地预览。合成邮箱和地址不应进入用户正在看的构建。

验收标准：

- [x] 默认与合成配置均可在隔离目录构建；不复制部署环境文件，不改原工作区的生成产物。
- [x] 保持默认预览运行，完整验收期间 88 次采样的构建标识、类型声明文件、HTML 和 CSS 保持不变。
- [x] 失败和取消路径清理自己的临时目录，合成构建编译期间实际收到 SIGTERM 后，报告标记取消且原预览不变。
- [x] 87 个单测、lint、构建及三套 smoke 通过：默认 773 项、合成公开记录 777 项、合成邮箱 761 项。新增检查读取实际生成的 CSS，不把它当作浏览器验收。

隔离目录只复制显式列出的源码、配置、脚本与公开资源，复用本地已安装依赖；不会读取和复制部署环境文件。主进程退出时，若 Darwin 短暂拒绝探测正在退出的同组 worker，会有限重试；拒绝持续且仍有成员时依然失败。生成报告以原子替换写入，强制杀死整个验收进程可能留下 Git 忽略的临时目录，但不会覆盖当前预览的构建。

## 后续目标：业务证据的键盘路径

优先原因：集团的业务证据是主要访客路径。旧版本按 Enter 可以滚动到分章，但实际焦点回到整份文档，没有落点提示。

- [x] 集团架构和三个业务分章接收原生锚点焦点，不拦截链接的默认行为。
- [x] Chrome 访客窗口实测中文 AI Agent Coach、Localhost 和英文 BioAxis：Enter 聚焦分章，下一次 Tab 到访问网站；从 AI Agent Coach 返回架构后聚焦架构标题。
- [x] 焦点提示只标记标题，架构链接有焦点时不执行入场动画。[章节焦点截图](../artifacts/2026-11-09-focus/chapter-after-native.png)。未点击外站链接。

## 后续目标：集团身份只陈述已确认的事实

优先原因：公开构建记录能说明建设活动，但不能自动成为集团的正式身份来源。[Schema.org 的 `sameAs`](https://schema.org/sameAs) 表示可明确识别同一实体的参考网页。

- [x] 页面保留公开档案入口；默认和合成配置的组织 JSON-LD 不把档案标为同一身份。
- [x] 默认仍无 `ContactPoint`，只有合成核验标记明确启用时验证邮箱模式。

最终通过 `check-local.mjs --fixtures`：87 个单测、lint、类型检查及三套生产构建；默认 781 项、合成公开记录 785 项、合成邮箱 771 项 smoke 断言通过。自动报告：`artifacts/local-checks/latest.json`。它不代替上述 Chrome/Safari 手工检查，也不证明线上版本或真实邮箱送达。

待所有者确认的发布事项：正式域名与公司身份、可以对外公开且实际收件的渠道、真实隐私与数据处理事实，以及独立的发布授权。未改写法律或隐私事实，未投递邮件、登录托管或发布。
