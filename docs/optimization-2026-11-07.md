# Xentra 下一阶段目标与本轮记录

范围：当前工作区，包含前一轮尚未提交的修改。不是线上版本审计，也不是发布记录。

## 判断

继续保留现有深色、象牙色与低饱和金属色系统。母公司架构、三家公司及公开业务证据已经有了清楚的基本结构；现在继续换主题或增加口号，回报低于补齐真实交互验收与维护可靠性。

上一轮的 32 个单元测试仍通过。本轮优先处理上一轮缺失的浏览器证据，以及源码中仍然存在的站点身份、日期和验收流程问题。

优先原因：源码与 HTTP 200 不能证明浏览体验。应先检查已经做出的设计，再决定要不要继续改。

验收标准：

- [x] 观察本地中文首屏和英文业务总览，不借用旧截图。
- [x] 核对业务导航与语言切换的目标地址保留对应章节。
- [x] 修正章节定位后覆盖整段的默认蓝色焦点框，保留标题级 brass 焦点提示。
- [x] 为桌面业务卡片的简介留出相同高度，避免“关键问题”行错位。
- [x] 完成最终构建后的桌面截图复验，移除整段蓝框并确认业务卡片内容行对齐。
- [ ] 完成移动断点、缩放和真实键盘菜单验收。

观察边界：内置浏览器连接仍不可用；本轮原生 Chrome 可用，但响应式工具控制不稳定。英文切换时曾观察到空白画面，直接刷新后恢复，不能据此认定永久故障，也不能把该次空白观察删除。尚未确认空白原因。

## 目标 2：统一集团站点身份与日期语义

优先原因：canonical、分享资源、站点地图与 JSON-LD 是同一品牌在站外的身份信号，不应随临时预览地址漂移。页面编辑也不能冒充业务证据的新核验。

验收标准：

- [x] 只采用显式站点 origin、生产域名配置或原有默认地址，不采用临时 `VERCEL_URL`。
- [x] 配置接受标准 HTTPS origin 与部署主机名，拒绝 HTTP、凭据、路径、查询串、片段及嵌入空白；错误不回显输入。
- [x] 首页 canonical、Open Graph、Twitter、JSON-LD 和 sitemap 使用同一来源。
- [x] 将首页编辑日期与外部证据核验日期分开；隐私说明、手记原日期不被自动刷新。
- [x] 最终默认配置构建与回归通过。

首页的 `2026-11-07` 仅表示本地页面改动日期，不代表已上线或外部业务刚被核验。原证据日期仍是 `2026-08-13`。

## 目标 3：可重复的一键本地验收

优先原因：多轮优化已经开始触及共用组件和元数据，手工拼接命令容易漏检查，也不利于以后持续迭代。

验收标准：

- [x] 增加 `pnpm check:local`，顺序执行单元测试、lint、Next build / 类型检查和生产模式 smoke。
- [x] 使用仓库默认公开配置的隔离子进程，不修改父进程或生产配置；关闭外站核验与 Next 遥测。
- [x] 临时服务器仅监听 loopback，使用系统分配的空闲端口。
- [x] 成功、失败、取消和超时均有清理路径；不通过端口查杀其他服务。
- [x] 生成忽略入 Git 的本地 JSON 报告，并明确标记未运行浏览器检查。
- [x] 最终全流程通过，核对临时端口与进程已经清理。

脚本会刷新本仓库的 `.next` 构建目录；运行前应停止共享这一构建目录的旧预览。它不会自动停止任何已有服务。字体依赖由现有 Next 构建链处理，这不是完全离线构建保证。

## 当日续轮：双语阅读与窄屏验收

继续保留现有配色、集团架构与三家公司入口。前一轮缺的是实际阅读证据；这轮先修看得见的中断，再加固反复运行的本地验收。

### 目标 1：不中断跨语言阅读

优先原因：已经点击过锚点的读者继续滚动后，地址栏中的旧片段不再代表当前章节。切换语言应保留读者所在的业务，而不是让人重新找一遍。

- [x] 地址栏仍在 `#companies`、页面实际滚动至 Localhost 时，新语言链接落到 `#localhost-chapter`；浏览器实测双向切换。
- [x] 使用原生链接，Cmd+点击打开新标签，原页不跳转。
- [x] `/privacy` 和 `/letter` 切换至自己的对应语言路由，不带首页片段。
- [x] 六项单元回归覆盖阅读位置选择；移除 BioAxis 章末重复的运营方法标签。

### 目标 2：窄屏标题与导航可用

优先原因：窄屏预览暴露英文主标题被裁掉，且前一轮没有完成手机键盘验收。这些问题比进一步调整颜色更影响首访质量。

- [x] Chrome 原尺寸预览确认实际布局宽度，320px 和 390px 英文标题的长单词完整显示，320px 中文首屏不拥挤。
- [x] 中文菜单实际键盘验证：Tab / Shift+Tab 循环、Esc 恢复焦点；进入方法章节后，滚动恢复、焦点落在章节。
- [x] 390×240 短屏可键盘到达最后一项；菜单打开时从 390px 切到 800px，桌面导航出现，滚动锁解除。

仅验证了本机 Chrome 响应式预览与桌面窗口。适配窗口模式会缩小实际布局宽度，最终截图使用 100% 并核对布局尺寸。未验证实体手机、Safari、屏幕阅读器或浏览器页面放大。

截图仅裁去浏览器界面：[英文 320px](../artifacts/2026-11-07-reading/english-320.png)、[英文 390px](../artifacts/2026-11-07-reading/english-390.png)、[中文 320px](../artifacts/2026-11-07-reading/zh-320.png)、[短屏菜单](../artifacts/2026-11-07-reading/menu-short-screen.png)。

### 目标 3：验收结束后不残留自建进程

优先原因：主进程退出不代表其派生进程退出。重复验收时，残留进程或继承的输出管道会污染下一次结果。

- [x] 先复现四种故障：主进程成功退出、失败退出、取消时遗留子进程，以及继承输出管道导致误报超时。
- [x] 仅清理脚本拥有的 POSIX 进程组，正常关闭超时后再强制结束，保留命令结果和输出；原有无关监听不受影响。
- [x] 最终完整本地验收通过：66 个单元测试、lint、Next build / TypeScript、695 项 smoke 断言；临时监听已释放。

自动验收报告为 `artifacts/local-checks/latest.json`；其中的 `browserChecks: "not-run"` 仅表示该命令未自动运行浏览器。上面的 Chrome 结果是独立手工验收。
