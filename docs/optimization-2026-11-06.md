# Xentra 本地优化复盘

日期：2026-11-06。基线：`40286d6`，包含进入本轮时工作区内尚未提交的视觉调整。
范围：当前仓库的源码、生成页面和本地 HTTP 检查；不代表生产版本。

## 方向判断

近黑、象牙色、低饱和金属色的方向可以保留。母公司架构、三家公司及其公开产品入口已经形成了基本骨架，不值得再推翻重做首屏或继续增加口号。

上一轮留在工作区的标题尺度、共用业务色、上下式集团架构和合作区调整也应保留。但本轮浏览器不可用，不能把这些调整描述为已重新完成视觉验收。

现在更值得优先做的是阅读效率与操作可靠性：

- 创始人摘要和业务引导重复讲“行业不同、信息很多、信任稀缺”，削弱了各段的职责。
- 移动菜单打开后跨到桌面断点，没有释放滚动锁的路径。
- 选中章节与取消菜单共用焦点恢复逻辑，都会把焦点送回菜单按钮。
- 原有 smoke 主要检查文案存在，没有完整检查本地链接目标，也没有交互状态逻辑测试。
- 产品证据是有日期的记录，不能在未重新核验外站时暗示它们仍是当前状态。

## 本阶段目标与验收

### 1. 可靠的导航与低动效模式

为什么先做：视觉完整不能弥补页面无法滚动或键盘操作丢失位置。

- [x] 菜单打开时隔离背景；Tab 循环可到达关闭按钮。
- [x] Esc 关闭后恢复按钮焦点和原来的滚动状态。
- [x] 选择章节后，先恢复背景再聚焦内容，不抢回按钮焦点。
- [x] 跨入 48rem 桌面断点（默认 768px）后关闭菜单、解除滚动锁，不聚焦已隐藏的按钮；与 CSS 使用相同单位。
- [x] 菜单高度受视口约束，短屏内容可以在菜单内滚动。
- [x] reduced-motion 禁用入场和滚动时间线动画，跳过链接也不强制平滑滚动。
- [ ] 实际浏览器中的键盘、缩放与手机复验；本轮连接不可用。

导航会话的 10 个单元测试通过。它们使用最小 DOM / 事件模型验证逻辑，不替代真实浏览器测试。

### 2. 首页去重，而不削弱业务证据

为什么接着做：现有信息足够，继续解释同一主张只会增加阅读负担。

- [x] 双语创始人摘要各缩为一段，保留第一人称与手记全文入口。
- [x] 业务引导只交代三个领域及共同标准，不再重述理念段。
- [x] 保留三家公司、九个登记入口、独立章节及既有路由。
- [x] 证据链接标签改为“已登记产品入口”，保留原核验日期，不伪装成新核验。

仅统计“创始人摘要 + 业务引导”的正文：英文从 88 词减到 46 词，约减少 48%；中文从 178 个非空白字符减到 102 个，约减少 43%。这不是整页减字比例。

### 3. 可重复的本地质量门槛

为什么现在做：前面多轮主要靠构建和文案标记，容易漏掉状态、链接与配置边界。

- [x] 新增导航会话、链接检查器和公开配置的单元测试，不新增依赖。
- [x] 生成后的六个双语页面逐一检查站内链接与锚点。
- [x] 四个首页导航目标均可接收程序化焦点。
- [x] 公开 URL 拒绝内嵌凭据、查询串和片段；错误不回显输入凭据。
- [x] 邮箱核验开关不能绕过格式与邮件参数检查；未核验时仍不发布邮箱。
- [x] 对最终工作区运行 lint、类型检查、build 和 smoke。

配置测试使用隔离子进程与合成值，不读取或修改生产配置。

最终本地结果：lint、TypeScript、Next build 均通过；32 个单元测试通过；674 项 smoke 断言通过，其中检查了六个双语页面的 110 个站内链接。没有运行外站核验或提交真实询盘。

## 不应继续凭空优化的部分

- 集团合作仍没有已确认的私密联系渠道。GitHub 只能作为公开构建记录，不能包装成已送达的咨询。
- 企业实体、团队履历、客户、经营数据和法律文本需要真实资料。不要用排版或文案补造这一层可信度。
- 品牌域名与邮箱的历史记录在 `external-dependencies.md`，不代表已在本轮重新确认所有权或收发状态。
- 本轮不访问或重新核验外部公司站点，不更新证据日期，不声称外部申请或询盘能成功送达。
